# Personal Portfolio Website

This repository contains the source code for my personal portfolio website, built with **HTML** and **CSS**. It is my first complete web project, designed to showcase my skills, projects, and contact details in a clean and responsive format.

## Features
- Responsive layout using CSS Grid and media queries
- Sticky navigation bar with smooth section linking
- Reusable card components for About, Projects, and Contact
- Theming powered by CSS variables (easy to customize colors, shadows, and borders)
- Project section with technology tags
- Contact section with direct email and LinkedIn links

## Technologies Used
- **HTML5**
- **CSS3**

## Structure
```
personal-website/ 
├── index.html # Main portfolio page
├── style.css # Stylesheet
```

## Deployment
You can host this site easily on **GitHub Pages**:

1. Push this repository to GitHub.  
2. Go to **Settings → Pages**.  
3. Set Branch = `main` and Folder = `/ (root)`.  
4. Your portfolio will be live at:  
[https://github.com/keerthana-2325/My-Portfolio-Website/](https://keerthana-2325.github.io/My-Portfolio-Website/)
